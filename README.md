# 체리컨슘

체리피커를 위한 카드 실적·혜택 관리 앱입니다.

## 소개

카드를 여러 장 쓰다 보면 이번 달 전월실적이 얼마나 찼는지, 지금 이 가게에서는 어느 카드를 내는 게 나은지 헷갈리기 쉽습니다. 체리컨슘은 이 두 가지를 알려주는 앱입니다.

## 기능

| 기능 | 설명 |
|---|---|
| 카드 등록 | 카드사와 상품명으로 검색하거나, 카드 앞면을 찍어 디자인으로 상품을 찾습니다 |
| 결제 기록 | 금액과 가게, 카드를 입력합니다. 저장하기 전에 예상 혜택과 실적 인정 여부를 보여줍니다 |
| 실적 현황 | 카드마다 이번 달 인정 실적과 다음 구간까지 남은 금액을 보여줍니다 |
| 가게별 추천 | 가게나 업종을 넣으면 보유한 카드를 기대 혜택 금액 순으로 정렬합니다 |

결제 내역은 사용자가 직접 입력합니다. 마이데이터나 알림 읽기는 쓰지 않습니다.

카메라로 카드를 알아볼 때는 기기 안에서만 처리합니다. 카드번호가 찍힌 사진은 서버로 보내지 않습니다.

## 기술 스택

아직 구현 전이고 아래는 계획입니다.

- **앱**: Flutter. Android 먼저
- **서버**: FastAPI, Postgres
- **데이터 파이프라인**: Python, Databricks
- **카드 인식**: 기기 안에서 도는 임베딩 모델과 최근접 이웃 비교

## 구조

```
앱 ──HTTPS──▶ 서버 ──▶ Postgres
                  ▲         │ 가명처리 후 내보내기
                  │         ▼
            오브젝트 스토리지 ──▶ Databricks
                                ① 카드 상품 수집·정제
                                ② 사용자 로그 분석
```

- 실적과 추천은 서버에서 계산합니다. 앱은 화면과 입력, 카메라 인식을 맡습니다.
- 파이프라인이 카드사에서 상품 정보를 모아 카탈로그를 만들고 서버에 넣습니다.
- 카드 인식에 쓰는 벡터는 파일로 올려두고 앱이 내려받습니다.
