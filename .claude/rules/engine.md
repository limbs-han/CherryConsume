# 계산 엔진 규칙

- 엔진은 DB도 화면도 모르는 순수 Dart다. 입력은 카탈로그와 결제 목록, 출력은 실적 현황과 추천 순위다.
- 엔진 함수는 예외를 던지지 않는다. 계산할 수 없는 경우는 설계 문서의 경고 코드로 돌려준다.
- 금액은 원 단위 int다. 비율은 64비트 정수 분수로 계산한다.
- 월 경계는 한국 시간 기준이다.
- 카드별 계산 테스트는 `app/test/engine/cases/`의 YAML 표 픽스처로 쓰고 한 테스트 함수가 전부 돈다. 기대값은 손계산 값이고 근거가 된 시나리오 번호를 적는다.
- 같은 입력은 항상 같은 출력을 낸다. 현재 시각은 인자로 받는다.
