# 스토어 등록 정보

Play Console의 기본 스토어 등록정보에 넣는 글이다. 작업 012 설계 3.1. 글자 수는 `backend/tests/test_store_listing.py`가 검사한다. 칸마다 아래 글을 그대로 붙여 넣는다.

## 앱 이름

```text
체리컨슘: 카드 실적·혜택 계산기
```

## 짧은 설명

```text
전월실적이 얼마 남았는지, 이 가게엔 어느 카드가 이득인지 알려 드려요
```

## 자세한 설명

```text
카드를 여러 장 쓰면 헷갈리는 두 가지를 알려 드려요.
이번 달 전월실적이 얼마나 남았는지, 지금 이 가게에선 어느 카드를 내야 이득인지요.

[이번 달 실적]
카드마다 이번 달 인정 실적과 다음 구간까지 남은 금액을 보여 줘요. 할부, 취소, 실적에서 빠지는 업종처럼 카드사마다 다른 규칙을 카드별로 따라 계산해요.

[어느 카드를 낼까]
가게나 업종을 고르면 가진 카드를 받을 혜택이 큰 순서로 늘어놓아요. 이번 달 한도가 남았는지, 조금 더 쓰면 받을 수 있는 혜택이 있는지도 함께 알려 줘요.

[결제 기록]
금액, 가게, 카드를 직접 넣거나 카드사 웹에서 받은 이용 내역 엑셀을 불러와요. 저장하기 전에 예상 혜택과 실적 인정 여부를 보여 줘요.

[폰 안에서만]
로그인이 없어요. 결제 기록과 계산은 폰 안에만 있고 밖으로 보내지 않아요. 카드번호도 받지 않아요. 폰을 바꿀 때는 설정에서 기록을 파일로 내보내 새 폰에서 가져와요.

[지금 쓸 수 있는 카드]
신한, KB, 현대, 하나, 롯데, 삼성, 우리, IBK, 카카오, 농협의 카드 20장이에요. 카드는 계속 늘려 가요.

[알아 두세요]
혜택은 카드사가 공개한 상품 설명으로 계산한 추정값이에요. 실제 청구 금액과 다를 수 있으니 정확한 혜택은 카드사에서 확인해 주세요.
체리컨슘은 카드사와 관계없이 개인이 만든 앱이에요.
```
