- 날짜: 2026-09-30

- 커밋: `e5aa21a` chore: 답에 영어 문장이 섞이면 끝내지 못하게 하는 Stop 훅 추가

## 요청

> 나한테 말할 때 또 영어 쓰네 자꾸 실망스럽게 하지마

## 과정

### 첫 결과

사과하고 영어로 쓴 안내를 한국어로 다시 썼다. 답에 영어 문장이 섞이면 보내지 못하게 막는 훅을 걸지 물었다.

### 수정 요청 1

> 응 훅 걸어줘

반영: Stop 훅 `korean_only.py`를 만들어 테스트 훅과 나란히 등록했다.
- 마지막 사용자 글 뒤로 쓴 글을 본다. 도구 사이의 진행 문장도 본다
- 코드 블록, 인라인 코드, 주소는 빼고, 한글이 없고 영어 낱말이 4개 이상인 줄을 영어 문장으로 본다. 한국어 문장 안의 영어 메뉴 이름은 걸리지 않는다
- 걸리면 끝내지 못하고 한국어로 다시 쓰게 한다. 같은 줄로 두 번 막지 않아 끝없이 되풀이되지 않는다
- 가짜 대화 기록으로 영어는 막히고 한국어는 통과하는 것을 봤다. 건 뒤로 실제 답에서 세 번 영어를 잡아냈다
- 이미 화면에 나간 문장은 되돌리지 못한다

### 수정 요청 2

> 둘 다 커밋해줘

반영: 과제 13 파일 네 커밋과 이 훅 한 커밋으로 나눠 커밋했다.

## 최종 결과

- Claude가 끝내기 전마다 이번 차례의 답에 영어 문장이 있는지 훅이 본다
- 한국어로 다시 쓰기 전에는 끝낼 수 없다
