## 과정

### 스토어 화면
여섯 장은 바탕색, 둥근 모서리, 위치가 같았고 위쪽 문구만 길이와 끝맺음이 들쭉날쭉했다. 문구를 12~15자, 명사 끝으로 맞춰 그림을 다시 만들고, README의 옛 화면 사진 넉 장 대신 이 여섯 장을 두 줄로 넣었다. 쓰지 않게 된 `docs/readme/` 사진은 지웠다. GitHub에서 넓은 화면은 석 장씩 두 줄로 보이는 것을 확인했다. 작업 012 설계 3절의 문구 표도 고쳤다.

### "자동으로 채웠어요"
결제 기록 화면에서 가게 이름으로 찾은 가맹점, 업종, 시각과 결제 방식을 보여 주는 요약 두 줄의 이름표다. 알림 읽기와는 상관이 없다. 가게가 엉뚱한 가맹점에 맞았을 때 사용자가 알아보는 곳이라 빼지 않고 이름표만 바꾸자고 했다. 세 안 가운데 "가게 이름으로 채웠어요"를 추천했다.
