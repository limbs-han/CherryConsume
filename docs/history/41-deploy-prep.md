### 첫 결과

### 수정 요청 1
> 이 크라우드는 별로야? 클라우드 사양 vCPU 2EA, Memory 4GB ( CPU : 2개, 메모리 : 4GB, 디스크 : 50GB) 클라우드 운영체제 rocky-8.10-base

반영: 사양은 충분하다고 답했다. 언제까지 쓸 수 있는지, 공인 IP와 포트, 도메인을 물었다. 보안 업데이트, 인증서, 백업을 직접 해야 한다는 것도 알렸다.
