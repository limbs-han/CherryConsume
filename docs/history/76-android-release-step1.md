- 선택: Play 개발자 계정 → 있다, 그 뒤에 만듦
- 선택: 시험자 모으기 → 아직 모르겠다

### 수정 요청 7
> 단계 1부터 시작

반영: 개인정보처리방침 쪽과 스토어 글을 쓰고 스토어 검사를 먼저 써 실패를 봤다. 그림을 그리다 출시 앱의 폰 홈 화면 아이콘이 Flutter 기본 로고인 것을 찾았다.
- 선택: 아이콘 바탕 → 크림 (추천)
- 선택: 그림 확인 → 이대로 (추천)

에뮬레이터를 1080×1920으로 바꿔 찍고 Pillow로 스토어 그림과 홈 화면 아이콘을 그렸다. 출시 묶음 파일을 만들어 서명 인증서, 대상 판 36, 권한을 확인했다. 위험 검토는 높음 0, 중간 4, 낮음 8이었다. 앱 안에 방침이 없다는 것, 문의 메일로 정보를 받는다는 것, 안전 조치, 이용자 권리와 보호책임자가 빠진 것, 에뮬레이터 시간대가 UTC라 결제 시각이 9시간 앞당겨 찍힌 것 들이다.
- 선택: 앱 안 방침 → 브라우저로 열기 (추천)
- 선택: 책임자 → Play 개발자 이름과 같게
- 선택: 문의 보관 → 답을 마치고 1년 뒤 (추천)

설정에 개인정보처리방침 줄을 넣고 url_launcher를 허용 목록에 더했다. 방침을 열두 절로 고치고 서울 시간대로 다시 찍었다. 앱에서 지운 결제와 카드가 폰 안에 남아 내보내기 파일에 들어가는 것은 코드를 바꾸지 않고 방침에 적었다.
