## 과정

### 정한 것
엑셀 열 짝 지문을 내보내기 파일에 담을지 물었다. 사용자가 "내보내기에서 빼기 (추천)"를 골랐다.

### 첫 결과
기록을 JSON 한 파일로 내보내고 한 트랜잭션에서 바꿔 넣는 가져오기, 설정의 두 줄, 자동 백업 끄기를 만들었다. 설계는 빈 백업 칸으로 끄기로 했지만, 공식 문서가 규칙이 없는 방식은 모두 켜진다고 적어 칸마다 모두 빼는 줄을 두었다.

### 에뮬레이터
백업은 "Backup is not allowed"로 막혔다. 내보내기는 시스템 저장 창으로 Downloads에 썼다. 가져오기는 성공했는데 "가져오지 못했어요"가 떴다. 화면을 다시 그리는 `setState`가 Future를 돌려 던진 예외를 가져오기의 catch가 받았다. try가 가져오기만 감싸게 고쳤다.

### 위험 검토
높음 0, 중간 3, 낮음 9건이 나왔다. 앱이 못 읽는 행을 받아 홈이 열리지 않는 길, 어느 폰에서도 가져올 수 없는 큰 파일, 새 폰 첫 실행의 엉뚱한 안내를 고쳤다. 파일은 칸 이름을 표마다 한 번 적는 모양으로 바꿔 줄였다.
