## 과정

### 첫 결과
과제 20을 시작하기 전에 정할 것 셋을 물었다.

선택: 새 카드를 골드에 넣는 길 → 손 승인으로 넣기
선택: 정답 예시 채점의 혜택 제목 새는 문제 → 정답 예시에서는 key만 주기
선택: 카드 조사 에이전트 설명 → 임시 폴더에 쓰게 고치기

셋을 반영하고, 앱은 표를 읽기만 하고 승인과 반려는 `cherry_approve`가 하는 설계안을 냈다.

### 수정 요청 1
> 진행해

반영: 앱의 기본 Python이 3.11이라 `cherry_core`를 깔지 않고, 미리 깔린 라이브러리만 쓰는 앱을 만들었다. 승인 작업에 초안 승인과 반려를 더했다. 위험 검토에서 높음 1건, 중간 8건, 낮음 9건이 나왔다.

선택: 내보내기 전에 쌓이는 앱 승인 → 밀린 폴더가 있으면 멈추기
선택: 낡은 초안 반려 뒤의 변경 → 사람이 손 승인으로 넣기
선택: 운영 앱 켜고 끄기 → cherry-admins에 관리 권한 주기

끊긴 앱 승인은 초안의 검수 기록 폴더로 이어 하게 고쳤다. 다시 검토의 중간 1건, 낮음 5건도 고쳤다.

### 수정 요청 2
첫 배포 출력을 붙였다. `valueFrom`이 무시된다는 경고 뒤 앱 시작이 멈췄다.

반영: 번들 설정의 이름을 `value_from`으로 고쳤다.

### 수정 요청 3
앱 화면 캡처를 붙였다. 새 카드와 사라진 카드 건 여섯 개만 보였다.

반영: 개발용 바뀐 원문 추출로 초안 하나를 만들게 했다.

### 수정 요청 4
틀린 값 승인과 제대로 된 승인의 앱 출력을 붙였다.

반영: 틀린 값은 검사에서 막혔고 제대로 된 초안은 다섯 단계를 마치고 대기 건이 닫혔다.

### 수정 요청 5
> 내가 끄고 차단 돌리긴 했어

반영: 앱이 이미 꺼져 있어 끈 앱이 0개였다. 앱을 켠 채로 다시 돌리니 비용 차단이 앱을 껐다.

## 최종 결과
검수 앱 `cherry-review-<대상>`이 개발용에서 돈다. 승인은 고친 카드 파일을 올리고 `cherry_approve`를 초안 번호로 돌린다. 끊기면 같은 버튼을 다시 누른다. 반려는 다음 초안이 생기면 시험한다. 운영 앱은 푸시하면 만들어지고 사람이 화면에서 켠다.
