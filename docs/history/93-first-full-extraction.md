## 과정

### 첫 결과
11월로 미룬 까닭은 10월 13일 체험 종료 전에 색인과 러너를 끝내기 어려워서였는데, 원문이 99.3% 모여 그 까닭이 없어졌다. 운영에서 새 카드 초안 30장을 시험해 16분, 초안 27, 사람이 정할 것 3을 봤다. 장당 33초라 나머지는 17시간쯤이고, 추출 작업의 시간 제한을 1시간에서 8시간으로 늘렸다.

### 수정 요청 1
> 그렇게 해

반영: 2026-10-05 23시 39분 첫 실행을 시작했다. 8시간 제한으로 07시 39분에 끊겼고 새 카드 초안 1,570장, 사람이 정할 것 573장, 모델 호출 실패 0이었다. 330장은 색인에 카드 종류가 없어서, 242장은 형식 오류로 대부분 포인트 혜택의 program이 빠졌다. 09시 01분 둘째 실행을 시작했다.

### 수정 요청 2
> 더하자

반영: 주 개발 세션이 작업 016에서 찾은 가맹점 별칭 `cu`의 "CU", `hollys`의 "할리스커피"를 위험 검토 뒤 운영 승인했다. 사용자가 export를 돌렸지만 두 번 실패했다. 돌던 사이 다른 세션 커밋이 master에 푸시됐고, 두 번째는 같은 실행을 다시 돌려 낡은 기준을 썼다. 새 실행에서 봇 커밋 `5353fcc`이 생겼다. 작업 014 뒤 새 경로의 첫 봇 커밋으로, 두 파일만 바꿨다.

### 수정 요청 3
> 1번 하자

반영: 형식 오류 답에 나온 포인트를 세어 KB 포인트리, 롯데 L.POINT, NH포인트, 에코머니, 해피포인트, 신세계포인트, BC카드 TOP포인트, IBK포인트, OK캐쉬백 아홉 개를 공식 문구로 조사해 운영 승인했다. 모두 1포인트 1원이다. 배민포인트는 공식 문구에 원 값이 없어 뺐다. 형식 오류로 넘긴 카드를 한 번만 다시 고르게 코드를 고쳤다. 위험 검토의 중간 지적대로 포인트 승인 뒤에 셋째 실행을 돌린다.

### 수정 요청 4
> 8시간 걸리니깐 그동안 할 거 없나 찾아봐

반영: 롯데 카드 종류를 채울 길을 찾았다. 공시 응답에는 종류 칸이 없고, 신용과 체크 목록은 판매 중 287장 가운데 130장만 담는다. 통합 검색의 `card` 묶음은 151장에 분류 코드가 있지만 역시 절반쯤이다. 상품 코드와 PDF 파일 이름으로도 갈리지 않는다.

## 최종 결과

- 첫 전체 추출은 둘째 실행 중이고, 끝나면 셋째 실행이 남은 카드와 형식 오류 카드를 새 포인트 목록으로 뽑는다.
- 운영 카탈로그에 가맹점 별칭 둘과 포인트 아홉 개가 들어갔다.
- 롯데 판매 중 카드 절반쯤의 종류는 공식 자료로 채울 길이 아직 없다.
