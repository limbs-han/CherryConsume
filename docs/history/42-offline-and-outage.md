## 과정

### 첫 결과
남은 일 가운데 사용자 설정 없이 할 수 있는 E24 오프라인 기록과 E26 서버 장애 화면을 슬라이스 9로 만들었다. 시나리오에 첫 출시 범위로 정해져 있었다. 설계 5i를 쓰고, 앱이 결제마다 번호를 붙여 서버가 한 번만 넣게 했다. 닿지 못한 결제는 폰에 모았다가 홈을 불러올 때 보내고, 홈은 마지막으로 받은 것을 보인다.

위험 검토에서 높음 1건, 중간 4건, 낮음 7건이 나왔다. 높음은 30초 끊기가 응답 몸통에만 걸려 서버가 답하지 않으면 끝없이 기다리는 것이었다. 보내는 사이 새로 모은 결제를 덮어쓰는 것, 서버 오류 결제 하나가 뒤를 막는 것, 401 뒤 앞사람의 홈이 남는 것도 고쳤다. 재검토에서 높음 0건, 중간 1건, 낮음 5건이 나왔다. 중간은 서버 전체가 멈춘 동안 모든 결제가 거절로 바뀌는 것이었고, 서버가 정상으로 답한 때만 세게 했다.
