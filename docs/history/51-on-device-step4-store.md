## 과정

### 첫 결과
서버 `cherry_api`의 카드와 홈, 결제 저장 전과 저장, 다시 계산, 기록과 고치기와 취소와 지우기, 답하기, 추천을 `app/lib/store/`와 `store/routes/`로 서버 파일 나눔과 함수 이름대로 옮겼다. 서버에 같은 이름 파일이 두 곳에 있어 경로 파일은 `routes/`에 두었다. 서버 시험을 같은 이름, 같은 입력, 같은 기대값으로 옮겼고, 로그인과 카탈로그 표처럼 폰에서 할 일이 없는 시험은 대조 스크립트의 예외에 까닭과 함께 적었다. 남은 빠짐은 단계 5의 엑셀 시험 30개다.

옮기다 같은 시각 결제 두 건의 id 순서가 무작위인 것을 찾았다. 시험 시계가 멈춰 있어 드러났고 서버도 같은 밀리초면 같았다. id가 늘 앞 id보다 크게 고쳤다. 시험을 쓰다 Dart 기록 안의 Map과 List가 값으로 비교되지 않아 몇 번 고쳤다.

DB 파일을 둘 폴더를 정하는 방법이 설계에 없어 물었다. 사용자가 Android 코드로 묻기를 골랐다. 4.1~4.6을 4.7 전에 검토하고 커밋하기로 했다.
