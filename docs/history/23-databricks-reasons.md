## 과정

### 첫 결과

- 대안의 최신 사실을 확인했다.
  - Databricks Free Edition은 상업 이용 금지, 서버리스 전용, SQL 웨어하우스 1개, 동시 작업 5개다.
  - Lakebase는 2026년에 정식 출시됐고, Delta 테이블과 양쪽으로 동기화되며 안 쓸 때 0으로 준다.
  - Snowflake Postgres는 2026-02-24 정식 출시됐다.
  - BigQuery는 매달 저장 10GB, 조회 1TB가 무료이고, 샌드박스는 테이블이 60일 뒤 사라진다.
- "써야만 했던 이유"는 없다고 솔직하게 적었다. 이 규모에서는 DuckDB와 Parquet, 또는 BigQuery가 더 단순하고 싸다. 고른 이유는 세 가지로 적었다. 배우려는 목적, 수집과 LLM 추출과 검증과 로그 적재를 Python 하나로 이어 예약 실행하는 것, Lakebase로 앱 DB와 분석을 합칠 길이다.
- `docs/databricks.md`를 새로 썼다. 용어, 이 프로젝트에서 하는 일, 맞는 점 8가지, 대안 4가지와 비교, 비용과 제약, 사용자가 직접 할 설정 순서 미리 보기가 들어 있다.
- 설정은 사용자가 직접 하고 Claude는 단계별로 안내한다는 방침을 설계 문서 2절 결정 표와 5절, `.claude/CLAUDE.md` 반드시 지킬 규칙, 기억에 남겼다.
- README 문서 표에 한 줄 더했다.
