### 수정 요청 4

> 1. zgm 할인카드를 히어로즈 체크카드로 바꾸고,
> 2. 모르겠어 들어가는 것 같아
> 3. 1일 2회
> 4. 청구서란 말이 없는거 보면 바로 할인 아닐까
> 5. 는 모르겠어

PX 할인 표 스크린샷을 함께 보냈다.

반영: 편의점 1일 2회를 확정했다. PX는 현장할인으로 바꾸고 확인 필요로 남겼다. 대중교통 통합한도와 메가오더 중복은 확인 필요로 남겼다. 스크린샷의 PX 표는 파일 값과 같았다. 히어로즈 체크카드는 조사 에이전트가 새 파일을 쓰고 다른 에이전트가 원문과 대조했다. 계산 값 불일치는 없었다. 대조가 끝난 뒤 zgm 할인카드 파일을 지웠다.
