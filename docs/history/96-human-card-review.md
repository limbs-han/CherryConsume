## 과정

진행 문서는 10월 6일 오류 수정까지만 적혀 있었다. 실제 Databricks 실행을 조회하니 오류 수정 뒤 재실행이 같은 날 18시 39분 성공으로 끝났다. 마지막 실행은 531장 중 초안 424장과 사람 판단 필요 107장을 남겼다.

전체 최신 초안 중 사람 판단 필요 상태이고 검수 대기가 열린 것은 259장이었다. 공식 원문 272개를 가져와 카드 종류, 규칙 형식 오류, 회사 업무용 카드, 오류 화면과 빈 답을 다시 나눴다. 같은 카드의 옛 초안과 닫힌 검수 대기는 넣지 않았다.

원문으로 카드 종류를 확인하거나 포인트 이름을 연결한 32장은 수정 내용을 기록했다. 그중 11장은 수정 사본을 만들고 기존 카탈로그 검사기로 확인했다. 9장은 오류 없이 통과했고 2장은 계산 조건 연결 오류가 남았다. 사본을 추가로 읽어 보니 시간 조건, 가맹점, 횟수와 핵심 혜택 누락이 있어 11장 모두 최종 승인 전에 더 고쳐야 했다.

## 첫 검토 결과

- 259장 전부의 초안 번호, 원문 경로, 공식 주소, 판단, 수정 근거, 남은 오류를 보고서와 JSON에 적었다.
- 기본 오류를 고친 카드 32장. 카드 종류 22장과 포인트 이름 14장이고 같은 카드가 겹친다.
- 회사 업무용 카드 12장은 개인 카드 대상에서 제외하는 것을 제안했다. 서비스 항목 2장은 상품 여부 확인으로 남겼다.
- 오류 화면 6장, 빈 답 2장, 혜택 없는 3장은 다시 수집하거나 추출하는 대상으로 나눴다.
- 이번 검토에서 즉시 승인할 카드는 0장이다. 형식 검사 통과와 금액·조건의 정확함은 다르다.
- 운영 표, 검수 대기, 골드와 저장소 catalog는 바꾸지 않았다. 수정 파일은 작업 폴더의 사본이다.

## 최소 검토로 승인할 사본 준비

사용자가 "내가 최소한의 검토로 앱에 카드를 넣을 수 있게 네가 잘 처리하란 뜻이였어"라고 했다. 분류에 그치지 않고 원문 대조, 사본 수정, 별도 카드 검토자와 돈 계산 검토, 실제 앱 엔진 손계산을 이어 했다. 중간 사용량 제한으로 멈춘 작업도 저장된 사본부터 이어 했다.

최종 승인 후보는 9장이다. 하나 렌탈 4장, KB 포인트리 체크 2장, 농협 미미와 zgm 할인, 신한 11번가 체크다. 연회비와 짧은 이름, 실적 제외, 최소 금액, 시간, 횟수, 공유 한도와 중복 처리까지 확인했다. 일반 관리비에 잘못 붙던 기본 할인, 기프트카드 제외를 일반 상품권까지 넓힌 범위, 앱에 나오지 않던 첫 결제 행사 안내도 고쳤다.

카탈로그 검사 오류·경고 0, 새 카드 손계산 120개와 기존 카드 손계산 281개 통과, 실제 승인 함수의 로컬 검사 통과다. 최종 돈 계산 검토는 문제 없음이다. 카드 9개와 공통 4개 파일을 업로드할 사본으로 만들었고 파일별 해시와 초안 번호도 남겼다.

전체 259장은 승인 후보 9장, 조사·작성 또는 계산 기능 보완 230장, 개인 신용·체크 대상 제외 제안 20장이다. 230장은 사용자가 다시 원문을 찾아 판단할 목록으로 넘기지 않는다. 교육비 범위, 발급월 기준, 연간 보상, 교통 실적 반영월, 출처 충돌은 조사와 개발 후속이다. 미미의 09:00 정각과 zgm 일부 페이 이름은 원문이 명확하지 않아 앱 확인 안내로 보존했다.

사용자에게는 [승인 목록](../work/008-catalog-all-cards/ready-2026-10-09/approval.md)과 운영 반영 여부만 제시한다. 승인 뒤 업로드와 운영 승인, 봇 내보내기 확인은 AI가 한다. 운영 반영은 아직 하지 않았다.

## 출시용 카드 추가 확보

사용자가 "당장 빠른 시일 내에 앱으로 출시해야하는데 투입 가능한 카드의 개수가 너무 적잖아"라고 했다. 이어 "끊겨서 마저 이어가"라고 요청해 사용량 제한으로 중단된 원문 검토와 계산 검증을 마쳤다.

기존 사람 판단 필요 259장 밖에 있던 일반 초안 2,162장도 가져와 검사했다. 오류 없이 계산 혜택이 있는 초안은 1,034장이지만 원문 대조를 마친 수는 아니다. 추천 27장과 하나 8장을 우선 조사해 21장을 추가했다. 14장은 후불교통 실적 반영월, 지정 가맹점 실적 제외, 월별 자격 변경 등 계산 기능이나 공식 표 확보가 필요해 후속으로 남겼다. 사용자에게 이 조건을 대신 판단해 달라고 넘기지 않았다.

최종 새 카드 후보는 첫 9장과 합쳐 30장이다. 운영 반영 뒤 기존 21장과 합쳐 51장이다. 카드와 공통·기존 분류 연결을 포함한 47개 파일, 초안 번호와 파일 지문을 [확대 승인 목록](../work/008-catalog-all-cards/release-2026-10-10/approval.md)에 준비했다. 새 카드 계산 391개, 기존 계산 281개, 유치원과 초중고 분류 연결 28개가 모두 통과했다. 실제 승인 함수와 상품 중복 검사, 독립 원문 대조와 돈 계산 검토를 했다. 운영 반영과 커밋은 아직 하지 않았다.
