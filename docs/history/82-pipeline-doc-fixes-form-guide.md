## 과정

### 첫 결과
넘겨받은 어긋남 가운데 문구만 낡은 13-38, 13-41~47을 고쳤다. robots.txt를 묻지 않고 받는 카드사와 쓰는 곳, 내보내기 폴더 36시간, 목록 비교는 사라진 카드만 올린다는 것, 비용 차단은 운영 앱만 끈다는 것, 지금 규칙 계산, 봇 커밋이 바꾸는 경로, 러너 끄는 창, 변경 데이터 피드를 켜는 때다. 설계 문서는 주 개발 세션의 고친 줄과 섞여 있어 내 두 줄만 올렸다.

다음으로 14단계 Google 설문을 준비했다. 설문은 사용자 계정 일이라 안내서 "카드 요청 설문"에 만드는 순서와 답 처리 순서를 적었다. 요청 카드를 표시해도 새 카드 초안 고르기는 추천만 앞에 두어, 요청 카드도 추천 다음으로 먼저 뽑게 했다. 주 개발 세션에 개인정보처리방침에 설문을 더하는 일과 앱 링크를 맡겼다.

남긴 것: 13-39 단종일 모르는 단종 카드는 사용자가 정한 것과 코드가 달라 사용자에게 묻는다. 13-40은 카탈로그 원본이라 다음 승인 때, 13-49 일부와 13-52는 집 PC 수집 결과를 보고 고친다.

## 최종 결과
