## 과정

### 첫 결과
지금 README에 맞춰 꾸미는 법을 표로 보였다. 가운데 머리, 배지, 화면 사진, 움직이는 그림, Mermaid 구조 그림, 강조 상자, 접기, 출시 뒤 스토어 배지다. 꾸미기 전에 정할 것 셋을 짚었다. 화면 사진은 git이 무시하는 `app/build/screens/`에 있어 따로 넣어야 한다는 것, README 맨 위에 걸면 스타크래프트 파생 아이콘이 더 눈에 띈다는 것, 라이선스 파일이 없다는 것이다.

### 수정 요청 1
> 1. 화면 사진은 따로 골라 넣고
> 2. 아이콘은 그대로 쓸거야 앱 아이콘으로도 쓸거고
> 3. 라이선스는 난 몰라

반영: 라이선스는 파일 없이 두었다. MIT 같은 라이선스는 저장소 전체를 가져다 써도 된다고 허락하는데, 우리가 권리를 갖지 않은 아이콘과 카드사 문구까지 허락하는 꼴이 되기 때문이다. 있던 화면 사진은 실제 폰 확인에서 고치기 전 것이라 에뮬레이터로 다시 찍었다. 오른쪽 위에 DEBUG 띠가 찍혀 화면 찍기 시험에서만 띠를 끄고, 상태 표시줄을 9:00과 알림 없음으로 맞춰 다시 찍었다. 홈, 카드 상세, 추천, 가게별 순위 4장을 540×1200으로 줄여 `docs/readme/`에 넣었다. README는 머리를 가운데로 모으고 배지 셋, 사진 4장, 폰 안 계산 강조 상자, Mermaid 구조 그림을 넣고 낡은 현재 상태와 진행 순서를 고치고 폴더 구조를 접었다. GitHub와 같은 규칙으로 그리는 미리보기로 모양을 확인했다.
