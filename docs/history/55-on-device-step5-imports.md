## 과정

### 첫 결과
서버의 파일 읽기와 판정, 저장, 되돌리기를 같은 함수 이름으로 옮겼다. 서버 시험 30개를 같은 이름으로 옮겨 이름 대조 빠짐이 0이다. archive의 Android 풀기는 다 푼 뒤에 넘겨 주어 압축 폭탄을 셀 수 없어서, 목차만 archive로 읽고 풀기는 dart:io로 조각마다 셌다. 에뮬레이터에서 Python이 만든 xlsx를 가져와 폰 DB까지 확인했다.

서버와 다르게 한 것 셋을 알렸다. 압축 폭탄 글, 한국어 엑셀 날짜 서식 번호, 경과 시간 서식이다. 단계 4 위험 검토 8번은 실제 카탈로그로 가릴 수 없어 시간 창을 바꾼 카탈로그로 따로 봤다.

### 위험 검토
