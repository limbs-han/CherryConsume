## 과정

### 첫 결과
지금 넣을 라이선스 파일은 없고 붙이지 않는 쪽이 맞다고 답했다.

- 출시가 목표라면 MIT나 Apache 같은 오픈소스 라이선스를 달면 안 된다. 남이 그대로 가져가 자기 이름으로 스토어에 올려도 막을 수 없다. 라이선스 파일이 없으면 기본이 모든 권리 보유다
- 먼저 저장소를 공개로 둘지 정해야 한다. 상업 출시가 목표면 비공개를 권했다
- 공개하면 아이콘이 걸린다. 스타크래프트1 컨슘 아이콘을 바탕으로 한 파생물이라 라이선스로 풀리는 문제가 아니다
- 지금 외부 코드는 ERD 페이지가 불러오는 Mermaid 하나다. MIT 라이선스이고 링크만 걸어 표기 의무가 없다
- 라이선스를 챙길 때는 나중에 온다. 카메라 인식 모델 MobileCLIP은 Apple 자체 약관을 따르는데 상업 이용이 되는지 아직 확인하지 못했다. 폰트와 카드 플레이트 이미지도 넣을 때 챙긴다
- 지금 넣으면 좋은 것은 라이선스가 아니라 README라고 권했다. 법률 자문이 아니라 일반 관행 기준이라고 밝혔다

### 수정 요청 1

icon-source가 커밋 `45b9f3d`에 그대로 남아 GitHub에 올리면 누구나 받을 수 있다고 알렸다. 그 커밋을 고쳐 써서 없던 것으로 만들기, 삭제를 새 커밋으로 남기기, 그냥 두기 셋 중 고르게 했다.

### 수정 요청 3
> 커밋을 고쳐써줘

앞서 물은 icon-source 처리 셋 중 첫째를 고른 답이다.

반영: 아이콘 커밋을 고쳐 써서 `45b9f3d`가 `c8185b9`가 됐다. 커밋을 고쳐 쓴다는 것은 이미 만든 커밋을 새 내용으로 바꿔 끼우는 일이다. 새 커밋에는 icon.png 하나만 있고 히스토리 어디에도 icon-source.webp가 없다. 파일이 하나가 되어 메시지도 `chore: 앱 아이콘 추가`로 줄였다. 지워진 파일은 로컬 저장소 안에 참조 없이 남지만 푸시할 때 올라가지 않는다고 알렸다.

### 수정 요청 4

### 수정 요청 7
> 커밋하고 https://github.com/limbs-han/CherryConsume.git 에 푸시해
>
> 이메일이랑 커밋 내용에 claude 안 들어가게 잘 했는지 꼭 체크하고

반영: 커밋 전에 검사부터 했다. Git 사용자 정보, 커밋 작성자, 커밋 메시지, 파일 내용은 깨끗했지만 두 곳에 흔적이 있었다.
- 파일 이름 `CLAUDE.md`
- 설계 문서 경로 `docs/superpowers/`. superpowers는 어시스턴트가 쓰는 도구의 플러그인 이름이라 읽는 사람에게 뜻이 통하지 않는다

두 파일 모두 이미 커밋에 들어가 있어서 이름만 바꾸면 옛 이름이 히스토리에 남는다고 알렸다.

- 선택: CLAUDE.md 처리 → 저장소에서 빼기
- 선택: `docs/superpowers/specs/` 경로 → docs/ 바로 아래로

추천안은 CONTRIBUTING.md로 이름 바꾸기와 `docs/specs/`로 옮기기였지만 둘 다 다른 안을 골랐다. 처리는 이렇게 했다.
- CLAUDE.md는 `.gitignore` 대신 `.git/info/exclude`에 등록했다. `.gitignore`에 적으면 그 파일에 이름이 남아 결국 올라가기 때문이다. `.git/info/exclude`는 내 컴퓨터에서만 쓰는 제외 목록이다. 파일은 컴퓨터에 남아 있어 어시스턴트는 커밋 규칙을 계속 읽는다
- 설계 문서를 `docs/2026-09-19-cherryconsume-design.md`로 옮기고 README와 문서 안 링크를 함께 고쳤다
- 옛 이름이 남지 않도록 체크섬을 기록한 뒤 커밋들을 처음부터 다시 만들었다. 이것을 히스토리 재작성이라고 한다
- 원격 저장소가 비어 있는 것을 확인하고 커밋 7개를 푸시했다

푸시 뒤 검사는 모두 통과했다.

| 검사 | 결과 |
|---|---|
| Git 사용자 이메일 | 확인 통과 |
| 커밋 7개의 작성자와 커미터 | 전부 jihan. Co-authored-by 없음 |
| 커밋 메시지 전문 | claude 없음 |
| 파일 이름과 내용 | claude 없음 |
| superpowers 흔적 | 없음 |
| 파일 체크섬 8개 | 푸시 전후 일치 |

Co-authored-by는 커밋에 공동 작성자를 함께 적는 줄이다.

끝으로 두 가지를 알렸다. 저장소가 공개 상태라 아이콘 파생물 문제가 그대로 적용되고, 설정에서 비공개로 바꿀 수 있다. 기본 브랜치가 master인데 GitHub 기본값은 main이라 나중에 도구를 붙일 때 어긋날 수 있다.
