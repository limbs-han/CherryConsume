## 과정

### 첫 결과
카드사별로 card-researcher 에이전트를 나눠 돌리는 빠른 조사 방식을 만들었다. 공식 원문은 핵심 숫자만 확인하고 재대조는 하지 않는다. 혜택을 더 주는 쪽은 빼고 덜 주는 쪽은 남긴다. 첫 승인 목록 38장을 만들었다.

### 수정 요청 1
> 지금 38장 먼저 운영에 반영해

반영: 공통 파일 손 승인 뒤 초안 승인으로 38장을 운영에 넣었다.

### 수정 요청 2
> 나머지 카드들도 앱에 넣을 수 있게끔 해 최대한 많이

반영: 둘째 134장, 셋째 67장, 넷째 166장을 차례로 조사, 묶음, 운영 반영했다. 현대카드는 공통 승인이 카드사 파일을 바꿔 초안 승인이 막혀 손 승인으로 넣고 초안을 닫았다. 연결이 자주 끊겨 반영 도구가 실행 번호를 남기고 다시 기다리게 했다. 카드가 늘며 박힌 장 수로 깨진 앱과 백엔드 시험을 계산값으로 고쳤다. 헬로모바일 별칭이 LG헬로비전 공식 이름과 겹친 것을 고치고 공식 이름까지 보는 검사를 넣었다.

### 수정 요청 3
> 둘 다 넣고 계속 진행해

반영: Two-in-One 이용자에게 적립이 크게 나오는 ROYAL BLUE POINT+와 등급 고객 전용인지 모르는 AVENUEL 두 장을 넣었다.

반영: 공식 원문에 원화 가치가 있는 포인트 8개를 더해 16장 중 11장을 풀었다. 업종이 없어 막힌 카드도 새 업종 8개(자동차 아래 전기차 충전, 주차장, 세차, 차량정비, 통행료와 전통시장, 골프)로 14장 중 11장을 풀었다.
