- 커밋: `9afc42e`, `b66be71`, `91be389`. 운영 손 승인 `r-20261005T094119Z-spend-defaults`

## 요청

> IBK, 카카오뱅크, 농협, 현대의 할부와 취소 처리를 약관에서 찾아 카드사 기본값으로 넣기
> 롯데 카드사 파일 메모의 목록 개수를 500에서 2000으로 고치기 하자
> deploy 뭘로 하면 돼

미뤄 둔 두 가지를 하자는 말과, 운영 검수 앱을 다시 배포하는 방법을 묻는 말이다.

## 과정

### 첫 결과
운영 검수 앱은 한 번도 배포된 적이 없었다. 화면에서 **Start** 뒤 **Deploy**로 배포 서비스 주체의 `apps/review` 폴더를 고르라고 안내했다.

카드 조사 에이전트 넷이 카드사마다 공식 상세 페이지, 상품설명서, 약관을 읽었다. IBK는 77장, 농협은 111장, 카카오뱅크는 약관 여섯 판과 안내장을 봤다. 셋 모두 전월 1일부터 말일, 할부는 승인한 달에 전액, 취소는 취소한 달로 나왔다. 현대는 카드마다 취소 반영 달이 달라 넣지 않았다. 롯데 메모는 사본에서 고쳤다.

### 수정 요청 1
사용자가 붙인 배포 기록과 함께 "앱상태 충돌됨 뜨고 주소들어가니" 앱을 쓸 수 없다는 화면이 나온다고 했다.

반영: 앱 기록을 보니 화면의 Deploy는 번들 설정의 실행 명령과 환경변수를 읽지 않아 `python app.py`로 켜지고 `KeyError: 'CHERRY_SILVER'`로 죽었다. 설정을 앱 폴더의 `app.yaml`로 옮기고, 스키마 이름은 앱 자원인 표의 전체 이름에서 읽게 해 `9afc42e`를 푸시했다.

### 수정 요청 2
> 검수 대기 제목 보여

> Starting app with command: [streamlit run app.py] 는 안보이긴 하는데 … 에 검수대기 3건 있긴 해

반영: 개발용 앱에서 제목이 보여 개발용 앱을 껐다. 운영 앱 기록에 `streamlit run app.py`와 배포 성공이 찍혔고 열린 건 3건이 보였다.

그 사이 근거 대조에서 값은 모두 원문과 맞았고 메모와 확인 필요 항목을 보충했다. 위험 검토는 중간 하나, 낮음 여덟이었다. 중간은 카카오뱅크에 installment가 빠져 기본값 묶음이 통째로 버려진다는 것이라 고쳤다. 사본으로 만든 앱 카탈로그가 지금 것과 바이트까지 같은 것을 확인하고 승인을 물었다.

### 수정 요청 3
> 승인

반영: 운영 손 승인을 돌려 다섯 단계가 모두 성공했다. 바뀐 파일은 4개, 새 검수 번호를 받은 개정은 0개다.

## 최종 결과

- 운영 검수 앱이 켜지고 열린 건이 보인다. 다 보면 **Stop**한다.
- IBK, 카카오뱅크, 농협 새 카드 초안은 원문에 할부와 취소 문구가 없어도 카드사 기본값과 확인 필요 항목으로 채워진다. 현대는 지금처럼 사람에게 간다.
- 다음 `export` 봇 커밋에서 저장소 카탈로그가 승인한 파일과 같은지 본다.
