## 최종 결과

- 운영 대시보드 "체리컨슘 운영"이 개발용과 운영에 있다. 수집 상태, 검수 대기, 쓴 금액을 보이고 열 때만 SQL 웨어하우스를 쓴다.
- 표 단위 계보가 `fetches` → `documents` → `changes`, `card_lists` → `queue`, `documents`와 `changes`와 `golden` → `drafts` → `queue`, `drafts` → `catalog_files`와 `card_revisions`로 이어졌다. 마지막 선은 검수 앱 승인일 때만이다.
- 글 뽑기는 pandas UDF로 Spark 안에서 계산하고, 목록 이름과 추출과 승인은 계산을 그대로 두고 쓸 때만 원래 표와 맞붙인다.
- 성공 기준 열넷이 모두 통과했다. 마지막 운영 `cherry_refresh`는 아래 수정 요청 16으로 확인했다.
- 체험이 끝나는 2026-10-13에 SQL 웨어하우스와 비용 차단 비용을 함께 정한다.
