### 첫 결과
Python 엔진을 `app/lib/engine/`으로 같은 파일 나눔과 같은 함수 이름으로 옮기고, Python 엔진 시험을 같은 이름으로 옮겼다. 조건 12, 실적 23, 혜택 44개 46번, 추천 9, 시안 10, 속도 2, 카드별 YAML 표 281경우와 표 검사 2, 명세서 대조 1이다. Dart 엔진 시험 390개가 통과한다. 경우 281, 혜택 기간 191, 기대 결제 787이 Python과 같고, 기대값 하나를 일부러 틀리면 혜택, 실적, 경고를 모두 잡는다. 시험 이름 대조 스크립트는 빠짐 0이다. 매개변수를 붙인 Dart 이름을 처음에 놓쳐 정규식을 고쳤다.

옮기다 찾은 것이 둘이다. Python JSON이 한도 조정의 적지 않은 칸을 `null`로 써서 IBK 나라사랑의 제한 없음과 섞였다. 적은 칸만 쓰게 고쳤다. 공휴일 목록 밖의 해를 옮긴 코드가 공휴일이 아니라고 짐작해, 설계 2절대로 모름으로 고쳤다.

다른 세션이 Python 속도 시험이 다른 시험 파일 뒤에 돌면 실패해 Stop 훅이 막는다고 알려 왔다. 해시 씨앗에 따라 갈렸다. 씨앗 1과 3은 늘 실패하고 2는 늘 통과했고, 엔진이 부르는 함수 수는 같았다. 쓰레기 수거 끄기와 다시 재기는 듣지 않아 되돌렸다. 재기만 새 프로세스에서 하게 고쳤다.

위험 검토는 높음 0, 중간 1, 낮음 6이었다. 중간은 폰 시간 날짜를 넘기면 그 달 실적을 못 찾는 것이었다. 엔진 입구가 날짜를 UTC 자정으로 맞추게 했다. 결제 값 검사, 결제 복사의 칸 비우기, 빈 결제수단, 공휴일 결제 시험, 앱이 담는 소수 범위, 덜 보던 시험 둘을 고쳤다. 이름별 개수 세기와 속도 시험의 난수 차이는 그대로 두었다.
