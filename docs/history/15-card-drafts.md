### 준비

설계 문서에서 카탈로그 파일 형식과 업종 목록, 후보 카드 목록을 다시 확인했다. 카탈로그는 카드마다 실적 구간, 혜택, 한도, 제외 업종을 적은 YAML 파일 모음이다. YAML은 사람이 읽고 고치기 쉬운 텍스트 데이터 형식이다. 업종 목록 파일과 검증 스크립트를 먼저 만들어 두었다.

### 조사 에이전트 다섯 개

에이전트는 따로 일하는 보조 작업자다. 카드사 공식 페이지를 보고 카드 파일을 쓰는 일을 다섯 묶음으로 나눠 동시에 돌렸다.

- 현대·KB국민
- 삼성·현대
- 롯데·하나
- 우리·NH·카카오뱅크
- 신한·IBK. 사용자 카드인 IBK 나라사랑카드가 들어 있고 마지막에 끝났다

첫 묶음이 끝났을 때 이미 틀로 담기 어려운 경우가 여럿 나왔다. 전가맹점 적립과 특정 업종 할인이 겹치지 않는 경우, 많이 쓴 영역 몇 곳에만 혜택을 주는 경우 같은 것이다.
