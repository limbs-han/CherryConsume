## 과정

### 카드 초안 커밋

15에서 만든 카드 20장 1판 초안을 먼저 커밋했다. 커밋 본문에는 다음을 적었다.
- 카드사 공식 페이지와 상품설명서에서 옮긴 20장, 업종 26개, 가맹점 별칭 121개다.
- 발급이 끝난 4장은 같은 카드사의 발급 중인 카드로 바꿨다. LOCA LIKIT 1.2는 LOCA CLASSIC, EVERY DISCOUNT는 카드의정석2 EVERY POINT, 쿠키 체크는 카드의정석 K-LIFE CHECK, zgm.히어로는 zgm 할인카드로 넣었다.
- 1판 검증 오류는 0개다. 작업 001에서 2판 형식으로 옮긴다.

커밋에는 카드 파일 20개, `catalog/categories.yaml`, `catalog/merchants.yaml`, `.claude/progress.md`가 들어갔다. 진행 상황 파일에서 "커밋하지 않은 것" 항목을 지우고, 카드 초안을 끝난 것 목록으로 옮겼다.

### 시작 화면 아이콘

요청의 "화면 와이어프레임의 제일 첫번째 화면"은 화면 시안 캔버스의 시작 화면이다. 먼저 캔버스 작업 파일이 어떻게 생겼는지 확인했다.

- 시작 화면에 있던 임시 도형을 `design/icon.png` 앱 아이콘으로 바꾸고 흰 타일 위에 올렸다.
- 고친 첫 화면을 화면 시안 캔버스에 올렸다.
- 저장소에 들어가는 화면 시안 PDF와 HTML을 캔버스 최신본으로 다시 만들었다.
- 첫 화면에 아이콘이 제대로 들어간 것을 확인한 뒤 커밋하고 푸시했다.

작업 도중 작업 기록 문서를 만들어 달라는 요청이 들어왔다. 아이콘 작업을 먼저 끝내 푸시한 뒤 이어서 하기로 했고, 그 기록은 19에 있다.
