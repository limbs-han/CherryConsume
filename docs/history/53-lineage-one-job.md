표 단위 계보를 살릴지 세 길을 냈다. 살리지 않기, 한 작업만 살려 보기, 모두 살리기다.

> 2번 해보자

## 과정

### 첫 결과
바뀐 것 고르기 작업이 계산한 줄만 Python에서 만들고 카드와 원문 칸은 `documents` 표와 맞붙여 쓰게 고쳤다. 개발용 원문 하나 끝에 영어 한 줄을 더해 `--add`로 넣는 시험 순서를 드렸다.

### 수정 요청 1
수집기 줄이 빠져 올릴 폴더가 없다는 오류를 붙였다.

반영: 빠진 수집기 줄을 다시 드렸다.

### 수정 요청 2
`바뀐 원문 0개`와 계보 화면을 붙였다.

반영: 고른 하나 트래블로그에는 날짜가 10월 3일로 적힌 시험 원문이 있어 비교 순서가 뒤집혔다. 가장 최근 원문이 지금보다 앞선 카드를 고르는 SQL을 드렸다.

### 수정 요청 3
`새 원문 0개`를 붙였다.

반영: 같은 날짜 폴더를 `cp -r`로 다시 올려 한 단계 더 들어가 올라간 것으로 보고, 파일 하나하나를 제자리에 올리는 명령을 드렸다.

### 수정 요청 4
`바뀐 원문 1개`와 계보 그래프를 붙였다.

반영: `documents`에서 작업을 거쳐 `changes`로 가는 선이 그려졌다. 결과를 계획에 적고 안내서의 PC 올리기를 파일 단위로 고쳤다.

## 최종 결과
바뀐 것 고르기 작업 하나는 Unity Catalog 계보가 살아났다. 계산한 값을 원래 표와 맞붙여 쓰면 선이 남는다. 나머지 여섯 작업을 이을지는 사용자가 정한다.
