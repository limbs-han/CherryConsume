## 과정

### 첫 결과
설계 5f와 계획을 쓰고 서버와 앱을 만들었다. csv, xlsx, html 표 파일을 메모리에서 읽고, 열 이름 사전으로 열을 찾고, 못 찾으면 사용자가 짝짓는다. 겹침과 취소를 판정한 미리보기를 보이고 저장하면 가져온 가장 앞 달부터 다시 계산한다. 묶음 단위로 되돌린다. 서버 묶음에 openpyxl, 앱에 file_picker를 더했다. 안드로이드 디버그 빌드를 확인했다.

위험 검토에서 높음 2건, 중간 14건, 낮음 19건이 나왔다. 돈 계산 규칙 넷을 물었다.
- 선택: 가져온 결제의 결제수단 → 실물카드, 간편결제는 가맹점명으로
- 선택: 직접 넣은 결제와의 겹침 → 10분 안, 이름 포함이면 같음
- 선택: 무이자 여부를 모르는 할부 → 유이자로 넣고 알림
- 선택: 시각이 없는 결제 → 시각을 모름으로

엔진에 시각을 아는가 칸을 더해 E57로 적었다. 가져온 취소를 줄마다 남겨 다시 올리기와 되돌리기를 고쳤다. 파일 이름은 남기지 않고 머리 줄은 해시로만 남긴다.

### 수정 요청 1
> 검토 끝나면 커밋하고 푸시해줘

반영: 재검토에서 높음 2건, 중간 4건, 낮음 13건이 나왔다. 저장할 때 판정받은 행을 모두 보내 미리보기와 같은 결과가 나오게 했다. zip은 실제로 풀며 크기를 센다. 새 행끼리 같은 승인번호는 한 결제로 본다. 미리보기는 몸통을 다 받은 뒤 DB 연결을 잡는다. 고치기에서 시각을 바꿔야 시각을 안다. 시각이 섞인 취소의 순서와 취소 시각을 고쳤다. 낮음은 고치거나 설계 5f에 한계로 적었다.
