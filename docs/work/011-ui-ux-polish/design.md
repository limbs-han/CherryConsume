### 2.4 짧은 이름 칸

- 카드와 카드사 파일에 `short_name`을 더한다. 적지 않아도 되는 글자 칸이다. 카드는 "신한 Mr.Life", "현대 ZERO", "IBK 나라사랑"처럼 카드사 짧은 이름과 상품의 핵심 이름이고, 카드사는 "신한", "IBK", "KB"다
- 화면은 칩, 줄, 버튼처럼 자리가 좁은 곳에서 `short_name`을 쓰고 없으면 `name`을 쓴다. 카드 상세 제목과 등록 시트 제목은 전체 이름을 쓴다
- 이 작업이 카탈로그 틀, 검사, 앱 JSON, Dart 모델에 칸을 더한다. 값은 Databricks 세션이 카드 20장과 카드사 10곳에 넣어 검수 승인으로 골드에 올리고, `export`가 저장소에 커밋한다. `catalog/`는 직접 고치지 않는다
- 값이 오기 전에도 화면은 `name`으로 돈다

## 3. 하단 탭

2026-10-04 아이콘 모양 세 가지와 추천 탭 그림 여덟 가지를 그려 보였다. 사용자가 모양은 "A 선에서 채움으로", 추천 탭 그림은 "카드와 별"을 골랐다.

- 막대는 시안대로 흰 바탕에 위쪽 1px `#E1E5EC` 선이다. Material의 알약 표시는 없다. G3
- 안 고른 탭은 회색 `#6B7684` 선 아이콘에 같은 색 글자다. 처음 그림의 `#8B95A1`은 흰 바탕에서 글자 대비가 3.0:1이라 앱의 보조 회색으로 바꿨다. 4.6:1이다. 고른 탭은 코발트 `#3457B2`로 채운 아이콘에 같은 색 굵은 글자다. 색과 모양이 함께 바뀌어 색을 잘 구별하지 못해도 고른 탭을 안다
- 그림은 홈이 집, 추천이 카드와 별, 기록이 줄 셋이 그어진 영수증, 설정이 톱니바퀴다. 24 칸 기준이고 선 굵기는 1.8이다
- 그림은 Dart의 `CustomPainter`로 직접 그린다. 네 그림에 아이콘 글꼴이나 SVG 패키지를 넣지 않는다. 같은 그림을 `design/tab-icons.svg`에 두어 시안을 고칠 때 쓴다
- 추천 탭에 체리를 쓰지 않은 것은 사용자가 고른 결과다. 체리 모양은 2026-09-21 결정대로 앱 아이콘과 이름에만 쓴다
