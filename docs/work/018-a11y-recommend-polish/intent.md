# 018 의도

## 왜

2026-10-17 에뮬레이터로 앱을 써 보고 WCAG 2.2 AA로 점검했다. 입력 칸 테두리와 예시 글자가 거의 보이지 않고, 화면 낭독기가 버튼을 영어로 읽고, 누르는 범위가 좁은 곳이 있었다. 추천 결과의 금액 칸은 확인을 눌러야 계산되고 "1만 원 기준"을 두 번 알렸다. 사용자가 함께 고치기로 했다.

## 성공 기준

1. 추천 결과 금액 칸에 "1만 원 기준" 알약이 없고, 입력이 0.3초 멈추면 확인 없이 다시 계산한다. 시험으로 확인한다
2. 입력 칸 테두리와 예시 글자가 흰 바탕에서 3:1과 4.5:1을 넘는다. 대비 시험으로 확인한다
3. 앱이 한국어 설정이라 뒤로 가기 버튼 이름과 날짜 고르기 창이 한국어다. 시험으로 확인한다
4. 결제 금액 칸이 제목을 이름으로 읽고, 기록 금액이 원까지 읽힌다. 시험으로 확인한다
5. 칩과 "답하면 더 받아요" 줄의 누르는 범위가 48dp 이상이다. 시험으로 확인한다
6. 앱 시험 전체와 작은 폰, 키보드 화면 시험이 통과한다
7. 판 번호 0.1.0+2로 출시 묶음 파일과 APK를 만든다

## 하지 않을 것

- 글자 200% 대응. 따로 한다
- 결제 기록 화면의 계산 방식. 이미 멈추면 계산한다
