# 012 계획

설계는 `design.md`, 의도는 `intent.md`다.

- Play Console, GitHub 저장소 설정, Google 그룹에서 누르는 일은 사용자가 한다. Claude는 넣을 값과 누를 곳, 무엇이 보이면 성공인지 쉬운 말로 안내하고 사용자가 붙여 준 결과로 확인한다
- 출시 키 파일과 `app/android/key.properties`는 열어 보지 않는다
- 시험자 이름, 메일, 시험자가 보낸 화면 사진은 저장소에 넣지 않는다
- 커밋은 사용자가 요청할 때만 한다
- 걸리는 시간은 단계 1이 1일, 2가 사용자 손으로 반나절, 3이 14일 대기 가운데 개발 반나절, 4가 신청 1시간과 심사 최대 7일이다
