# 012 Android 출시 준비

2026-10-05 작업 011을 끝낸 뒤 시작했다. 설계 문서 하위 프로젝트 5다. 완료 기준은 "Play 스토어 심사 통과"다. 2026-10-05 사용자가 이 의도를 확인했다.

## 왜

- 실제 출시가 목표다. 앱은 2026-10-04 실제 폰에서 카드 등록부터 엑셀 가져오기까지 모두 됐고, 작업 011로 화면도 다듬었다
- Play 스토어에 내려면 앱 밖의 준비물이 필요하다. 개인정보처리방침 주소, 스토어 등록 정보, 데이터 보안 양식, 512 아이콘과 기능 그래픽, 스크린샷이다
- 설계 문서 7절에 열어 둔 위험 둘을 출시 전에 정하기로 했다. 기록 내보내기를 알리는 법과 아이콘 저작권이다

## 이미 아는 것

| 사실 | 한 줄 설명 |
|---|---|
| 앱 이름표 `com.cherryconsume.app`, 판 0.1.0+1 | Play에 한 번 올리면 이름표는 바꿀 수 없다 |
| 출시 서명 키가 있다 | 작업 006 단계 7에서 사용자가 만들었다. `docs/release-setup.md` |
| 대상 Android 판 36 | Flutter 3.44.8 기본값이다. Play는 2026-08-31부터 새 앱과 업데이트에 36 이상을 요구한다. 2026-10-05 Play 고객센터에서 확인했다 |
| 권한은 인터넷 하나 | 카탈로그 받기에만 쓴다. 결제 기록, 카드, 답은 폰 밖으로 나가지 않는다 |
| 로그인이 없다 | Play의 계정 삭제 요구는 계정을 만드는 앱에만 해당한다. 설계 문서 4.3 |
| 2023-11-13 뒤에 만든 개인 개발자 계정은 비공개 시험을 거친다 | 시험자 12명 이상이 14일 동안 이어서 참여해야 정식 출시를 신청할 수 있다. 2026-10-05 Play 고객센터에서 확인했다 |
| 아이콘이 스타크래프트 파생이다 | 2026-10-02 사용자가 수익이 없으니 그대로 두기로 했다. 권리자가 신고하면 Play에서 내려갈 수 있다고 알렸다 |

## 이미 정한 것

| 질문 | 답 | 한 줄 설명 |
|---|---|---|
| Play 개발자 계정 | 있다. 2023-11-13 뒤에 만든 개인 계정 | 가입비와 본인 확인은 끝났다. 시험자 12명이 14일 동안 이어서 참여하는 비공개 시험을 거쳐야 정식 출시를 신청할 수 있다. 2026-10-05 사용자가 답했다 |
| 시험자 모으기 | 아직 모른다 | 시험에 꼭 필요한 것만 먼저 갖춰 비공개 시험을 열고 나머지는 14일 동안 한다. 모으는 법은 설계에서 다시 정한다. 2026-10-05 사용자가 답했다 |
| 범위 | Play가 요구하는 것과 기록 내보내기 알리기 | Play가 요구하는 것은 개인정보처리방침, 데이터 보안 양식, 콘텐츠 등급, 스토어 등록 정보, 아이콘과 그래픽, 스크린샷, 비공개 시험, 정식 출시 신청이다. 기록 내보내기 알리기는 설계 문서 7절이 출시 준비에서 정하기로 한 위험이라 넣는다. 이용약관과 아이콘 다시 그리기는 뺀다. 2026-10-05 사용자가 따로 고르지 않아 이 기본값으로 정했다 |
| 개인정보처리방침 주소 | GitHub Pages | 저장소가 공개라 무료이고 고친 기록이 git에 남는다. 주소에 GitHub 사용자 이름이 들어간다. 2026-10-05 사용자가 정했다 |

## 성공 기준

1. 개인정보처리방침이 GitHub Pages 주소에서 로그인 없이 열린다. 앱이 실제로 하는 일과 맞는다. 모으는 것, 폰 밖으로 나가는 것, 인터넷으로 하는 일, 기록 내보내기 파일이 가는 곳을 적고 앱 코드와 하나씩 대조한 표가 `design.md`에 있다
2. Play 데이터 보안 양식의 질문마다 고른 답과 근거가 `design.md`에 있고 개인정보처리방침과 어긋나지 않는다. 사용자가 Play Console에 넣어 앱 콘텐츠의 모든 항목이 완료로 보인다
3. 스토어 등록 정보가 저장소에 있다. 앱 이름 30자, 짧은 설명 80자, 자세한 설명 4000자 이내다. 512×512 아이콘, 1024×500 기능 그래픽, 폰 스크린샷 2장 이상이 Play가 요구하는 크기인지 검사로 확인한다
4. 기록 내보내기를 알리는 법을 설계에서 정하고 앱에 넣는다. 화면 시험이 그 알림을 확인하고 앱 시험 전체가 통과한다
5. 출시 키로 서명한 앱 묶음 파일이 만들어진다. 대상 Android 판이 36 이상이고, 합쳐진 권한 목록이 인터넷 하나인지 확인한다. 권한이 더 있으면 왜 있는지 적는다
6. 비공개 시험에 시험자 12명 이상이 14일 동안 이어서 참여한 것을 사용자가 Play Console에서 확인한다
7. 정식 출시 신청이 승인되고 Play 스토어에서 앱이 공개되어 누구나 설치할 수 있다

## 하지 않을 것

- iOS 앱스토어 출시. Android 출시 뒤 따로 작업을 만든다. 2026-10-04 사용자가 정했다
- 결제 알림 읽기. 하위 프로젝트 6으로 출시 뒤에 한다
- 수익화. 사용자가 먼저 꺼낼 때만 다룬다
- 이용약관. Play가 요구하지 않는다
- 아이콘 다시 그리기. 2026-10-02 정한 대로 지금 아이콘을 내보내기만 한다
- Play Console에서 누르는 일. 계정, 결제, 양식 제출, 시험자 목록은 사용자가 한다. Claude는 넣을 값과 누를 곳을 쉬운 말로 안내한다
