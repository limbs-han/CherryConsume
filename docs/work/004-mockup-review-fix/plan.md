## 실행 중에 바꾼 것

- 설정과 상태 모음은 한 화면에 다 들어가지 않아 세로로 늘렸다. 설정 1040px, 상태 모음 2240px이다. 실제 앱에서는 스크롤하는 화면이다. 나머지 12개는 390×844 그대로다
- 상태 모음에 두 가지를 더했다. 카드마다 다른 답과 가게를 못 찾을 때다. 앞의 것은 시안 카드에 사실과 옵션이 없어 실제 카드로 보여 준다. 뒤의 것은 검토에서 짚었는데 설계 3절 표에 빠져 있었다. 시나리오 E16이다
- 한국어가 낱말 중간에서 끊겨 모든 화면의 줄바꿈을 띄어쓰기 기준으로 바꿨다
- 기록 화면의 요일이 틀려 고쳤다. 2026년 9월 18일은 금요일, 19일은 토요일이다
- 저장소 HTML에서 화면 위의 이름이 잘려 보이지 않던 것을 고쳤다. 전부터 있던 문제다
- 5b 추천 결과를 핵심만 남겼다. 사용자가 결제 직전에는 어느 카드가 가장 이득인지만 필요하다고 했다. "조금 더 쓰면"과 잔여 한도, 건당·하루 조건을 빼고 카드마다 이유 한 줄만 둔다. 캔버스 17판
- 같은 기준으로 다른 화면의 부가 정보도 덜었다. 추천 첫 화면의 잔여 한도, 홈의 할인 잔여와 결제 건수·합계와 "1장 더 채우면 돼요", 첫 시작 홈의 안내 카드, 가져오기의 처리 설명을 뺐고 미리보기 안내를 한 문장으로 줄였다. 결제 기록의 "건당 최대 1,000원"과 등록 시트의 혜택 목록 줄은 사용자가 남기기로 했다. 캔버스 19판
- "실적 인정" 표시를 모두 뺐다. 실적에 들어가는 것은 당연하고, 빠지는 결제만 "실적 제외"로 알린다. 결제 기록과 미리보기 두 곳이다. 캔버스 20판
- 결제 기록의 예상 혜택 금액이 세로로 어긋나 왼쪽 두 줄의 가운데에 맞췄다. "자동으로 채웠어요"는 그림자 카드가 아니라 가게 칸과 같은 테두리 입력칸으로 바꾸고 값을 보통 굵기 두 줄로 나눴다. 캔버스 21판
