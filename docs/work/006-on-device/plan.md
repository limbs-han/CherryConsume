설계는 `design.md`, 의도는 `intent.md`다. 순서는 설계 8절이다.

- 단계마다 앱이 돌고 시험이 모두 통과한 채로 끝낸다
- 4~7단계는 돈 계산, 개인정보, DB가 바뀌어 `risk-reviewer` 검토 뒤 사용자 확인을 받는다

- 시험 이름은 옮기는 Python 시험의 함수 이름과 같게 짓는다. 설계 3절
