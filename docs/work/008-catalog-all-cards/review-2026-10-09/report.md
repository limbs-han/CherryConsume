# 사람 판단이 필요한 카드 초안 두 번째 검토

이 문서는 첫 재분류 결과다. 사용자 요청에 맞춰 수정과 독립 검토를 이어 한 최신 결과는 [9장 승인 목록](../ready-2026-10-09/approval.md)이다.

2026-10-09 Databricks 운영 표에서 최신 새 카드 초안만 골랐다. 상태가 needs_human이고 검수 대기가 open인 259장이다. 카드당 최신 초안 한 개이며, 272개 공식 원문에서 근거를 읽었다. 마지막 추출 실행의 107장보다 전체 누적 대상이 크다.

운영 표, 검수 대기, 골드와 저장소 catalog는 바꾸지 않았다. 수정 파일은 이 폴더의 사본이다. 이번 검토는 전체 재분류와 기본 오류 수정, 만들어진 사본 11장의 추가 돈 계산 검토다. 259장 모두의 혜택 금액·조건을 최종 승인한 것은 아니다.

중복을 뺀 32장의 기본 오류를 일부 또는 전부 해결했다. 카드 종류를 확인한 카드는 22장, 포인트 이름을 연결하거나 바로잡은 카드는 14장이다. 두 가지 수정이 같은 카드에 있는 경우가 있어 합계는 서로 다르다.

11장 수정 사본 중 카탈로그 검사에서 오류가 없는 것은 9장이다. KT할부 Plus와 K-22 Point는 규칙 연결 오류가 남았다. 검사 통과는 계산이 맞다는 뜻이 아니다. 추가 검토에서 실제 조건 누락과 잘못된 대상 범위를 찾았으므로 이번 검토의 즉시 승인 대상은 0장이다.

## 우선 처리할 것

1. 수정 사본 11장의 아래 지적부터 고친다. 실적 구간의 종료 조건, 공유 한도, 결제 수단, 시간 조건을 원문과 다시 맞춘다.
2. 회사 업무용 12장과 서비스 항목 2장을 새 카드 색인에서 따로 구분할지 정한다. 실제 반려와 색인 수정은 아직 하지 않았다.
3. 우리카드 오류 화면 6장은 원문을 다시 확보하고, 빈 답 2장과 혜택 없는 3장은 다시 추출한다.
4. 나머지 카드 종류와 비율·금액 조건은 공식 상품설명서나 발급 신청의 상품 구분에서 더 확인한다.

사이트 공통 메뉴의 신용카드·체크카드 낱말과 공통 주의 문구는 종류의 근거로 쓰지 않았다. IBK는 개인용과 기업용 설명서가 함께 있는 상품을 회사 업무용으로 단정하지 않았다. 비율 범위·마일·포인트 배수·달러 금액에 임의의 원 금액을 넣지 않았다.
