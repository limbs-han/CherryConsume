## 앱에 남길 확인 안내

- 미미의 오전 9시 정각 포함 여부는 원문이 명확하지 않다. 현재 계산은 09:00 미만이며 확인 필요를 표시한다.
- zgm 디지털 구독은 공식 사이트 직접 카드결제가 조건이다. 원문이 이름을 밝히지 않은 일부 페이 제외는 확인 필요를 표시한다.
- 매출표 접수일, 입점 점포, 포인트 일부 사용, 과거 최초 결제 이력처럼 결제 입력으로 알 수 없는 조건은 문장으로 보존한다. 신한 체크 첫 결제 행사는 조건 안내만 남기며 계산 합계에 더하지 않는다.

## 나머지는 사용자가 다시 조사하지 않는다

259장 중 승인 후보 9장, 조사·작성 또는 계산 기능 보완이 필요한 230장, 개인 신용·체크 대상에서 제외를 제안한 20장이다. 230장을 사용자 판단 대기로 표시하지 않는다. 전체 카드별 근거와 후속은 [전체 결과](all-results.json)에 있다.

교육비 범위를 좁히지 못한 카드, 발급월과 사용월이 다른 행사, 연간 이용액·적립 포인트의 추가 보상, 실물·모바일 교통 실적 차이, 출처 간 조건 충돌은 이번 승인에서 뺐다. 반려나 검수 대기 닫기는 하지 않았다.

## 승인 뒤 처리

사용자는 위 9장과 확인 안내의 운영 반영 여부만 한 번 결정한다. 파일 업로드, 공통 항목 승인, 카드별 승인과 검수 대기 닫기, 봇 내보내기 확인은 AI가 처리한다. 원본 catalog는 봇이 반영한다.

올릴 파일과 해시·초안 번호는 [승인 묶음](approval-manifest.json)에 있다. 현재 운영 상태와 기준 해시는 실행 직전에 다시 확인한다. 로컬에서 실제 승인 함수 검사도 통과했고 바뀌는 파일은 카드 9개와 공통 4개다.
