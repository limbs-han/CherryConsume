## 결과

- 2026-10-17 단계 2. `app/lib/store/custom.dart`가 입력을 카탈로그 카드 한 벌 JSON으로 바꾸고 `withCustom`이 켤 때와 만들거나 고친 뒤 카탈로그에 더한다. `app/lib/store/routes/custom.dart`가 만들기, 고치기와 다시 계산, 고치기 화면 입력, 비슷한 카드에서 시작을 맡는다. 마이그레이션 7번은 `custom_cards`와 `transactions.spend_excluded`다. 엔진은 결제의 실적 제외만 새로 본다. 복사한 혜택은 화면이 보낸 key로 바탕 규칙에서 찾아 화면이 보낸 JSON을 규칙에 넣지 않는다. 시험 `app/test/store/custom_cards_test.dart` 10개를 먼저 써 실패를 봤다. 앱 시험 4,989개 통과
